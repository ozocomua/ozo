ПОЛНЫЙ ИНВЕНТАРИЙ САЙТА OZO (ozo.com.ua)
=============================================

1. TECH STACK
--------------
Фреймворк: Next.js 16.2.4 (App Router, React 19, TypeScript 5.7.3)
База данных: Prisma ORM 6.19.3 / MySQL
UI: Tailwind CSS v4.2.0 + shadcn/ui (Radix UI — полный набор компонентов)
Анимации: tw-animate-css, sonner (toast), lucide-react (иконки)
Формы: react-hook-form + zod
Другое: embla-carousel-react (карусель), react-quill-new (rich-text редактор), recharts (графики)
Деплой: pm2, порт 3002, next build + next start
Изображения: unoptimized (без оптимизации Next.js)


2. ВСЕ СТРАНИЦЫ
-----------------

Публичные:
- / — Главная: баннер, категории, товары, бренды, блог, Viber-CTA, JSON-LD StoreSchema

- /checkout/pay — Страница оплаты (редирект)

Админ-панель (/admin):

- CRUD категорий
- CRUD брендов
- CRUD блога (rich-text редактор)
- Заявки на звонок

4. API РОУТЫ
--------------
Публичные:
- /api/search — поиск товаров (name, sku, description, до 8 результатов)
- /api/products — список товаров (AJAX-пагинация, сортировка)
- /api/catalog — обновление цен корзины
- /api/checkout — оформление заказа (транзакция, списание stock, Telegram-уведомление, MyIBAN)

- /api/callback — заявка на звонок + Telegram-уведомление
- /api/reviews — отзывы о магазине (пагинация)
- /api/settings — публичные настройки
- /api/posts — посты блога (пагинация)
- /api/orders/[id] — информация о заказе

Админские:
- /api/admin/login, /api/admin/logout
- Полный CRUD: товары, категории, бренды, заказы, заявки, настройки
- Загрузка изображений, создание ТТН, калькулятор, финансы

6. ДЕТАЛЬНЫЙ ОПИСАНИЕ ФУНКЦИЙ
--------------------------------

6.1. Корзина
- React Context + localStorage (ключ 'ozo-cart')
- addToCart, removeFromCart, updateQuantity, clearCart
- Автообновление цен через /api/catalog при открытии
- Модальное окно с итоговой суммой и переходом на /checkout
- Проверка maxStock при добавлении и изменении количества

6.2. Поиск
- Десктоп: строка в header, debounce 350ms
- Мобильный: кнопка → анимированная строка + крестик закрытия
- API /api/search: поиск по name, sku, description (contains)
- Результаты в выпадающем списке (фото, название, цена)
- Закрытие по клику вне компонента (mousedown + touchstart)
- Сообщение "Нічого не знайдено"

6.3. Оформление заказа
- Форма: ФИО, телефон +380, "не звонить"
- Доставка: поиск города НП (debounce 400ms), топ-5 городов
- Тип доставки: отделение / почтомат / курьер (3 кнопки)
- Поиск точки выдачи, для курьера — адрес
- Оплата: карта (MyIBAN) или наложенный платёж
- Предупреждение о наложке (настраивается в админке)
- Серверная валидация stock через транзакцию
- Telegram-уведомление админу

6.4. Отзывы
- Два типа: о товаре (productId) и о магазине (isStoreReview)
- Все отзывы создаются скрытыми (isPublished: false)
- Админ публикует через панель модерации
- Золотые звёзды (amber-500)
- Средний рейтинг вычисляется на сервере

6.5. Галерея товаров
- Десктоп: главное фото слева + миниатюры справа (вертикальный скролл)
- Мобильные: фото сверху + миниатюры снизу (горизонтальный скролл)
- Лайтбокс: черный фон 90%, стрелки (чёрные полупрозрачные), счетчик N/M
- Свайп влево-вправо (touch, порог 60px)
- Клавиатура: Escape, стрелки
- Блокировка скролла body при открытом лайтбоксе

6.6. Варианты / бандлы / связанные товары
- Варианты: выбор размера/объёма, обновление цены, bottom sheet
- Версии товара: пилюли-ссылки на другие варианты
- Бандлы: "Разом дешевше" — три товара, расчёт выгоды
- "З цим товаром купують" — сопутствующие товары
- "Вам також може сподобатись" — товары из той же категории

6.7. SEO
- generateMetadata на всех ключевых страницах
- Канонические URL
- JSON-LD: StoreSchema, Product (с Offer, ReturnPolicy, ShippingDetails), BreadcrumbList
- Динамический sitemap.xml (все страницы + категории + товары)
- Динамический robots.txt
- MetaTitle/MetaDescription из полей БД для товаров, категорий, блога
- favicon, apple-touch, android-манифест

6.8. Блог
- Публичный: список с пагинацией, детальная статья
- Статья: контент HTML, дата, CTA-кнопка (настраивается), рекомендованные товары
- Админка: rich-text редактор (react-quill-new)
- Статусы: черновик / опубликовано

6.9. Callback-виджет
- Плавающая кнопка "Phone" (z-9999, правый нижний угол)
- Форма: имя, телефон (форматирование +380), вопрос
- Состояния: idle → submitting → success (автозакрытие 3.5 сек)
- Telegram-уведомление админу
- Открывается из футера через кастомное событие

6.10. Админ-панель
- Полный CRUD: заказы, товары, категории, бренды, блог, заявки, отзывы
- Статусы заказов: drag-down меню
- Теги заказов: срочно, уточнить, проблема оплаты/доставки, VIP
- Создание ТТН через API Новой Почты
- Дублирование товара
- Загрузка изображений
- Калькулятор прибыли
- Финансовый контроль (автосоздание записей через Telegram webhook)
- Настройки предупреждения о наложенном платеже
